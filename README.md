# Livisha Hasija — Resume Portfolio Website

A responsive personal resume website created using HTML and CSS for the Web Development mid-term project.

## Sections
- Home / Hero
- About
- Education
- Skills
- Selected Projects
- Contact

## CSS concepts demonstrated
- Element, class and ID selectors
- CSS variables and consistent colour palette
- Flexbox and CSS Grid
- Sticky positioning
- Responsive media queries
- Hover states and transitions
- Typography, spacing and visual hierarchy
- Reusable card and tag components

## Files
- `index.html` — website structure and content
- `style.css` — all styling and responsive rules

## Hosting
Upload these files to the GitHub repository and enable GitHub Pages from the repository settings.
